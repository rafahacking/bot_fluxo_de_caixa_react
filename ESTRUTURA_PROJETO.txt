================================================================================
COMO USAR
================================================================================

1. Instalar dependências:
   pip install -r requirements.txt

2. Ajustar configurações em config.json (opcional)

3. Preparar dados de entrada na pasta dados/

4. Executar:
   python main.py

5. Verificar resultados na pasta saidas/

================================================================================
PERSONALIZAÇÃO
================================================================================

Edite config.json para ajustar:

✓ horizon_days: Dias a projetar (padrão: 60)
✓ pct_recebimento_no_vencimento: % recebido no vencimento (padrão: 0.7)
✓ pct_recebimento_apos_tolerancia: % recebido após atraso (padrão: 0.3)
✓ dias_tolerancia_recebimento: Dias de atraso médio (padrão: 3)
✓ usar_sazonalidade_semana: Aplicar sazonalidade (padrão: true)
✓ reservas_minimas_caixa: Limite de alerta (padrão: 10000)
✓ janela_media_movel_dias: Janela para média móvel (padrão: 30)
